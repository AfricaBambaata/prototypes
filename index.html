        Aanmelden voor beheer

        Om wijzigingen op te slaan heeft deze pagina een sleutel van GitHub nodig. Die maak je één keer aan per apparaat.

        1. Maak een sleutel aan op GitHub (opent in een nieuw tabblad).
        2. Kies bij Repository access: Only select repositories → prototypes.
        3. Zet bij Permissions → Actions op Read and write en Contents op Read-only.
        4. Klik Generate token, kopieer de sleutel en plak hem hieronder.
